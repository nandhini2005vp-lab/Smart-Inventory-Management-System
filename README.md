# Smart Inventory Management System

## Project Overview
A desktop inventory management application developed using Python, Tkinter, and SQLite.

## Technologies Used
- Python
- Tkinter
- SQLite
- SQL

## Features
- Add Products
- View Products
- Search Products
- Edit and Delete Products
- Stock In / Stock Out
- Low Stock Alerts
- Inventory Dashboard
- Input Validation

## Learning Outcomes
- Python application development
- SQLite database management
- SQL CRUD operations
- GUI development using Tkinter
